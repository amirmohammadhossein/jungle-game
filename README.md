# جنگ جنگل 🌴🔫

بازی شوتر خانوادگی، ریل‌تایم، قابل دسترس برای NVDA.

## چطور آنلاینش کنیم؟ (رایگان، با Render.com)

1. یه حساب رایگان تو [github.com](https://github.com) بساز (اگه نداری).
2. یه ریپازیتوری جدید (Repository) بساز، مثلاً به اسم `jungle-shooter`.
3. تمام فایل‌های این پوشه (`server.js`, `package.json`, پوشه‌ی `public`) رو توش آپلود کن.
   - تو گیت‌هاب: دکمه‌ی "Add file" → "Upload files" → همه‌ی فایل‌ها رو بکش و بنداز.
4. برو [render.com](https://render.com) و با همون حساب گیت‌هاب ثبت‌نام کن.
5. رو داشبورد Render: **New +** → **Web Service**
6. ریپازیتوری‌ای که ساختی رو انتخاب کن و وصلش کن.
7. تنظیمات زیر رو بذار:
   - **Build Command:** `npm install`
   - **Start Command:** `node server.js`
   - **Instance Type:** Free
8. دکمه‌ی **Create Web Service** رو بزن و چند دقیقه صبر کن.
9. وقتی دیپلوی تموم شد، یه لینک بهت می‌ده مثل `https://jungle-shooter-xxxx.onrender.com` - همینو برای فامیل بفرست.

### ⚠️ نکته‌ی مهم درباره‌ی نسخه‌ی رایگان Render
سرویس رایگان بعد از ۱۵ دقیقه بدون بازدید "می‌خوابه". دفعه‌ی بعد که کسی لینک رو باز کنه، ۳۰ تا ۶۰ ثانیه طول می‌کشه سرور بیدار بشه و صفحه بالا بیاد - این طبیعیه، فقط باید صبر کنه.

## چطور اجرا کنم رو کامپیوتر خودم (برای تست قبل از آپلود)؟

اگه Node.js نصب داری:
```bash
npm install
node server.js
```
بعد آدرس `http://localhost:3000` رو تو مرورگر باز کن.

## راهنمای کلیدها (تو خود بازی هم با دکمه‌ی ؟ قابل دیدنه)

| کلید | عملکرد |
|---|---|
| جهت‌نماها | حرکت (جلو/عقب/چپ/راست) |
| Q / E | چرخش به چپ/راست |
| Ctrl | شلیک |
| H | اعلام سلامتی |
| C | اعلام مختصات |
| T | رادار (دشمن‌های نزدیک) |
| W | موقعیت نزدیک‌ترین دشمن |
| 1 / 2 / 3 | سوییچ اسلحه |
| R | پر کردن اسلحه (ریلود) |
| F1 | جدول امتیازات |
| Enter | زنده شدن بعد از مرگ |

همه‌ی کنترل‌ها روی صفحه هم به‌صورت دکمه‌های لمسی/موس موجودن - برای بازیکن‌های بینا یا موبایل.

## نکات فنی برای توسعه‌ی بعدی
- کد سرور تو `server.js` هست: منطق بازی، ترکیب سلاح‌ها، برخورد با موانع، محاسبه‌ی جهت/فاصله برای رادار.
- کد کلاینت تو `public/game.js` هست: رندر بوم (Canvas)، کنترل‌ها، صداهای سینتزشده با Web Audio API، و اعلام‌های ARIA برای NVDA.
- اطلاعات کاربرها تو فایل `users.json` (رمزها هش‌شده با `crypto.scrypt`) ذخیره می‌شه - این فایل خودکار ساخته می‌شه، نیازی به دست‌زدن نداره.
- تعداد و موقعیت درخت‌ها/سنگ‌ها تو تابع `generateObstacles` در `server.js` قابل تغییره.
- آمار اسلحه‌ها (دمیج، برد، ظرفیت) تو آرایه‌ی `WEAPONS` در `server.js` هست.
